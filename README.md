# FIRM

Federated Information Resource Manager (FIRM)

## Setup

1. Make sure you have Python and uv installed
2. Activate the virtual environment:
   ```bash
   . .venv/bin/activate
   ```

## Running the Server

To run the server, execute:
```bash
python main.py
```

The server implements a basic message handler that returns a placeholder response. You can customize the handler in `main.py` to implement your specific logic.
